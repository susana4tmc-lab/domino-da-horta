# Dominó da Horta

Jogo de plantas companheiras do projeto **Mercado "À Mão de Semear"** (Ficha 15 do Manual do Professor do 1.º Ciclo).

É uma página única (`index.html`): não precisa de instalação, não pede registo, não guarda dados e não envia nada a ninguém. Funciona em telemóvel, tablet e computador.

## Como se joga

Cada planta tem um símbolo (uma forma e uma cor) que indica o grupo a que pertence. Encosta peças com o **mesmo símbolo**.

- **1 jogador:** tens as 20 peças. Ganhas quando as colocares todas. Se fores bem sucedido, as pontas do dominó ficam com o mesmo símbolo: as 20 peças fecham um círculo.
- **2 jogadores (à vez):** cada jogador tem 10 peças. Ganha quem colocar primeiro todas as suas.
- **Dica** mostra as peças que encaixam. **Desfazer** anula a última jogada.

## Os cinco grupos

| Símbolo | Grupo | Plantas |
|---|---|---|
| Quadrado azul | Clube do Sabor | Tomate, Manjericão, Beterraba, Espinafre |
| Triângulo verde | Equipa das Raízes | Cenoura, Cebola, Alho, Rabanete |
| Retângulo roxo | Grupo de Crescimento | Alface, Pepino, Curgete, Calêndula |
| Círculo laranja | Escudo Natural | Abóbora, Capuchinha, Couve, Alecrim |
| Losango vermelho | Família de Estrutura | Morango, Ervilha, Feijão, Milho, Borragem |

## Publicar no Vercel

1. Criar este repositório no GitHub com o `index.html` na raiz.
2. No Vercel: **Add New Project** → importar o repositório → **Framework Preset: Other** → deixar o comando de build vazio → **Deploy**.
3. O endereço fica algo como `domino-da-horta.vercel.app`. Cada alteração enviada para o GitHub atualiza o jogo.
